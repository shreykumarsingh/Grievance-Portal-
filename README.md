# आवाज़ (Awaaz) - Grievance Portal 🏛️

**आवाज़** is a secure, full-stack MERN application for filing and tracking public grievances. It bridges the gap between citizens and government officials through a transparent, role-based system.

## 🚀 Key Features
- **Multiple Roles:** Dedicated dashboards for Citizens, Officers, and Admins.
- **Grievance Lifecycle:** Securely file, route, and track complaints.
- **Secure Auth:** JWT-based authentication with Bcrypt encryption.
- **Email Integration:** Automated recovery via Nodemailer.

## 🌟 Why Awaaz?
- **Transparency:** Citizens can track complaints and see assigned officers in real-time.
- **Efficiency:** Automatic routing ensures grievances reach the right district and department.
- **Accountability:** Digital logs prevent "lost files" and ensure officials are held responsible.
- **Accessibility:** 24/7 digital platform, eliminating the need for physical paperwork.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, TailwindCSS.
- **Backend:** Node.js, Express.js, MongoDB.

## 🔨 How to Install
1. Clone the repository to your local machine.
2. Install dependencies for both frontend and backend using `npm install`.
3. Set up the MongoDB database and configure connection settings in the backend `.env`.
4. Start the backend server using `npm run start` in the server directory.
5. Start the frontend server using `npm run dev` in the client directory.
6. Access the application in your web browser at `http://localhost:5173`.
